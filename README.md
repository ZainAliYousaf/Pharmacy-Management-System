# Pharmacy-Management-System
The Pharmacy Management System is a desktop-based application developed to manage pharmacy operations efficiently through an integrated frontend and backend system. The project was built as part of my Computer Science learning journey to gain practical experience in software development and database management.

This system helps in managing medicines, inventory records, sales transactions, and sales history while maintaining organized database operations. The application provides an easy-to-use interface for handling day-to-day pharmacy activities in a structured and efficient way.

# Features:
Medicine management
Inventory tracking
Sales and billing management
Sales history records
Database record management
User-friendly desktop interface
CRUD operations for efficient data handling

# Technologies Used
C# (WinForms) – Desktop application development
SQL Server – Database management system
Concepts Learned

Through this project, I gained hands-on experience in:

CRUD (Create, Read, Update, Delete) operations
Database integration using SQL Server
Frontend and backend connectivity
Real-world application workflow
Data management and system organization
Purpose of the Project

The main goal of this project was to strengthen my understanding of desktop application development and database systems by building a practical real-world management system.
